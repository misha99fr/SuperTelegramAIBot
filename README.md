# SuperTelegramAIBot

Tг-бот с кучей функций в одном файле. Написан с помощью Claude Free. Работает с Tooken Club (https://tooken.club/), а вообще с любым API, совместимым с OpenAI.

## Че собственно говоря умеет

- Чат с ИИ. Доступ к нему открывается после мини-игры /survkey: бот загадывает число, у игрока три попытки. Админ может выдать доступ вручную.
- Погода по городу (/weather Москва), данные берутся с Open-Meteo, ключ не нужен. ИИ тоже умеет её запрашивать сам.
- Магазин смартфонов с каталогом, карточками товаров и листанием кнопками. ИИ отвечает про товары только по каталогу и ничего не выдумывает.
- Баллы ProTutu, смотреть можно только в личке (/points).
- Плагины: обычные .txt с дополнительными инструкциями для ИИ. Каждый плагин подписывается ключом Ed25519, без верной подписи он не загрузится. Подпись можно отозвать, плагин можно отключить, а установку новых запретить.
- Баны по username, при смене ника бан не слетает.
- Экстренное отключение с оповещением во все чаты и кнопкой отмены. Есть фейковый вариант (/fakestop), о нём знает только консоль.
- Управление прямо из консоли, где запущен бот. Там же можно написать ИИ обычным текстом или попросить его отправить сообщение в чаты.
- Права для ИИ (/giveperms, /givepermanentperm): с ними он сам может включать и выключать плагины, пользоваться /stop и остальными админскими командами.
- Режимы crazy mode и supercrazy mode, лучше не включать при живых пользователях. Что они делают, смотри в коде.
- По умолчанию бот отвечает только на ответы (reply) на свои сообщения и на упоминания. Выключается командой /replymode off.

## Установка

Нужен Python 3.10 или новее.

    pip install -U "python-telegram-bot>=21" openai httpx cryptography

Переменные окружения:

    TELEGRAM_BOT_TOKEN   токен от @BotFather
    OPENAI_API_KEY       ключ Tooken Club (или другого провайдера)
    OPENAI_BASE_URL      по умолчанию https://tooken.club/v1
    OPENAI_MODEL         по умолчанию gpt-6.1-sol
    ADMIN_ID             твой Telegram ID, можно несколько через запятую

Свой ID можно узнать командой /myid у запущенного бота. Перед публикацией замени значение ADMIN_ID по умолчанию в коде на своё или оставь пустым и задавай через переменную.

Запуск:

    python bot.py

## Подпись плагинов

    python bot.py genkey мойключ
    python bot.py sign плагин.txt мойключ
    python bot.py verify плагин.txt

Закрытые ключи лежат в папке keys, никому их не показывай и не заливай в репозиторий. Туда же не нужны access.json, banned.json, points.json и остальные json рядом с ботом, это данные пользователей.

## Команды

Полный список команд консоли выводится при запуске и по /help. Команды Telegram для обычных пользователей: /start, /shop, /weather, /survkey, /points, /why, /reset, /myid.
